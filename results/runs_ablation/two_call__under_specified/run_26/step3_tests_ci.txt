### (b) GitHub Actions Workflow

```yaml
# .github/workflows/test_pipeline.yml

name: Python Package

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:

    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pytest
        pip install scikit-learn
        pip install pandas
        pip install joblib

    - name: Run tests
      run: |
        pytest test_fraud_detection_pipeline.py --disable-warnings
```

### Explanation

- **Pytest Test File:** The test file includes fixtures and test functions for each part of the pipeline. It uses `monkeypatch` to mock I/O operations like reading CSVs and saving models to avoid actual file operations during tests.
  
- **GitHub Actions Workflow:** This workflow checks out the repository, sets up Python, installs necessary dependencies, and runs the tests using `pytest`. It triggers on pushes and pull requests to the `main` branch.

By implementing these tests and CI workflow, you ensure that your pipeline is tested automatically, making it robust and reliable.
