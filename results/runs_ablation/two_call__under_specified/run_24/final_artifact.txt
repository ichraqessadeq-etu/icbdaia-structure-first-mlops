Here's the full Python module for the fraud detection pipeline:

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score

class FraudDetectionPipeline:
    def __init__(self, random_state=42):
        self.random_state = random_state
        self.model = RandomForestClassifier(random_state=self.random_state)

    def load_data(self, filepath):
        """Load dataset from a CSV file."""
        return pd.read_csv(filepath)

    def preprocess_data(self, df):
        """Preprocess the data, including handling missing values and encoding categorical features."""
        # Example: Fill missing values and encode categorical data
        df = df.fillna(0)
        df = pd.get_dummies(df, drop_first=True)
        return df

    def split_data(self, df, target_column):
        """Split the data into train and test sets."""
        X = df.drop(target_column, axis=1)
        y = df[target_column]
        return train_test_split(X, y, test_size=0.2, random_state=self.random_state)

    def train(self, X_train, y_train):
        """Train the RandomForest model."""
        self.model.fit(X_train, y_train)

    def evaluate(self, X_test, y_test):
        """Evaluate the model."""
        predictions = self.model.predict(X_test)
        return {
            "accuracy": accuracy_score(y_test, predictions),
            "precision": precision_score(y_test, predictions),
            "recall": recall_score(y_test, predictions)
        }

    def predict(self, X):
        """Make predictions on new data."""
        return self.model.predict(X)
```

### Explanation:

1. **`FraudDetectionPipeline` Class**: Encapsulates the entire pipeline, including data loading, preprocessing, splitting, training, evaluation, and prediction.

2. **`load_data` Method**: Loads data from a CSV file using Pandas.

3. **`preprocess_data` Method**: Handles basic preprocessing such as filling missing values and encoding categorical variables. You can expand this with more sophisticated preprocessing as needed.

4. **`split_data` Method**: Splits the data into training and testing sets.

5. **`train` Method**: Trains a Random Forest classifier. You can replace this with any other model as desired.

6. **`evaluate` Method**: Evaluates the model on the test set and returns common metrics.

7. **`predict` Method**: Generates predictions for new data.
