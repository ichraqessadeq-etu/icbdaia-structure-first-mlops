    pipeline = FraudDetectionPipeline()
    X_train, X_test, y_train, y_test = pipeline.split_data(sample_data, 'is_fraud')

### (b) GitHub Actions Workflow

Below is a GitHub Actions workflow file that you can place in `.github/workflows/test.yml` to automate testing with pytest:

```yaml
# .github/workflows/test.yml

name: Python package

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:

    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v3

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pytest scikit-learn joblib pandas

    - name: Test with pytest
      run: |
        pytest
```

This configuration will run the tests using Python 3.8, install the necessary dependencies, and execute your `pytest` test suite whenever code is pushed to the `main` branch or a pull request is made. Adjust the Python version and dependencies as necessary for your project.
