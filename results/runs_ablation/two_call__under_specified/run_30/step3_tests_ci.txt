### (b) GitHub Actions Workflow File

Create a file named `.github/workflows/python-package.yml` for your GitHub Actions workflow:

```yaml
name: Python package

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  build:

    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pytest scikit-learn pandas joblib

    - name: Run tests
      run: |
        pytest
```
