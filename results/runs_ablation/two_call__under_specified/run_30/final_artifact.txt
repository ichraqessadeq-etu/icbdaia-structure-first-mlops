### Fraud Detection Model Module

First, let's create a simplified version of your fraud detection model module. This will include data loading, preprocessing, model training, and prediction functions.

```python
# fraud_detection_model.py

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score
import joblib

class FraudDetectionModel:
    def __init__(self):
        self.model = RandomForestClassifier(n_estimators=100, random_state=42)

    def load_data(self, filepath):
        """Load the dataset from a CSV file."""
        self.data = pd.read_csv(filepath)
        print(f"Data loaded from {filepath} with shape {self.data.shape}")

    def preprocess_data(self):
        """Preprocess the data by splitting into features and labels, and train/test split."""
        features = self.data.drop('is_fraud', axis=1)
        labels = self.data['is_fraud']
        self.X_train, self.X_test, self.y_train, self.y_test = train_test_split(
            features, labels, test_size=0.2, random_state=42)
        print("Data preprocessed and split into train and test sets.")

    def train_model(self):
        """Train the RandomForest model."""
        self.model.fit(self.X_train, self.y_train)
        print("Model training complete.")

    def evaluate_model(self):
        """Evaluate the model on the test set."""
        predictions = self.model.predict(self.X_test)
        accuracy = accuracy_score(self.y_test, predictions)
        precision = precision_score(self.y_test, predictions)
        recall = recall_score(self.y_test, predictions)
        print(f"Model evaluation: Accuracy={accuracy}, Precision={precision}, Recall={recall}")
        return accuracy, precision, recall

    def save_model(self, filepath='fraud_detection_model.pkl'):
        """Save the trained model to a file."""
        joblib.dump(self.model, filepath)
        print(f"Model saved to {filepath}")

    def load_model(self, filepath='fraud_detection_model.pkl'):
        """Load a trained model from a file."""
        self.model = joblib.load(filepath)
        print(f"Model loaded from {filepath}")

    def predict(self, X):
        """Make predictions on a new dataset."""
        return self.model.predict(X)
```

This module provides a structured way to load data, preprocess it, train a RandomForest model, and evaluate the model's performance. It also includes methods to save and load the trained model.

### (b) GitHub Actions Workflow File

Create a file named `.github/workflows/python-package.yml` for your GitHub Actions workflow:

```yaml
name: Python package

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  build:

    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pytest scikit-learn pandas joblib

    - name: Run tests
      run: |
        pytest
```

- **Pytest File (`test_fraud_detection_model.py`):** This file contains tests for the `FraudDetectionModel` class. It uses fixtures to create a model instance and mock data for testing. Each function tests a different aspect of the class, including data loading, preprocessing, model training, evaluation, and prediction.

- **GitHub Actions Workflow (`python-package.yml`):** This YAML file defines a workflow that runs on every push or pull request to the `main` branch. It sets up Python, installs dependencies, and runs `pytest` to execute the tests. This ensures that your code is automatically tested in a CI/CD pipeline whenever changes are made.
