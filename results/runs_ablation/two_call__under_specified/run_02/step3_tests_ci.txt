### (b) GitHub Actions Workflow

Here's a GitHub Actions workflow file for running the tests:

```yaml
# .github/workflows/python-app.yml

name: Python application

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:

    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pytest scikit-learn pandas joblib

    - name: Run tests
      run: |
        pytest
```
