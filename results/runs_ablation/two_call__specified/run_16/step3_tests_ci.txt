import pandas as pd

### (b) GitHub Actions Workflow

```yaml
name: CI

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - name: Check out the repository
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
        pip install pytest mlflow scikit-learn

    - name: Run tests
      run: |
        pytest -v
```

### Explanation

- **Pytest Test File**: Contains tests for each function in the pipeline. It uses `pytest` fixtures and `monkeypatch` to mock external dependencies like file I/O and MLflow logging.

- **GitHub Actions Workflow**: Automates the testing process on every push or pull request to the main branch. It sets up the Python environment, installs dependencies, and runs the tests using `pytest`.

Make sure to adjust any paths and dependencies according to your project's structure and requirements.
