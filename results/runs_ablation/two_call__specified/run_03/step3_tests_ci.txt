### (b) GitHub Actions Workflow

```yaml
name: Python Application Test

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout repository
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pytest scikit-learn pandas mlflow

    - name: Run tests
      run: |
        pytest -v
```

### Explanation:

- **Pytest Test File**: The test file uses `pytest` to create unit tests for each function in the pipeline module, making use of fixtures and assertions to check expected outcomes.

- **GitHub Actions Workflow**: The workflow is triggered on pushes and pull requests to the `main` branch. It performs the following:
  - Checks out the repository code.
  - Sets up a Python environment.
  - Installs necessary dependencies.
  - Runs the tests using `pytest`.

This setup ensures that any changes to the pipeline module are automatically tested using GitHub Actions, maintaining the integrity and reliability of your codebase.
