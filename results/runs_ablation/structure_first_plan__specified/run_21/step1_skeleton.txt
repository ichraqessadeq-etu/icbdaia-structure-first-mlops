### CI Workflow: YAML Outline

#### `.github/workflows/ci-cd.yml`

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  setup:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.8'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt

  test:
    runs-on: ubuntu-latest
    needs: setup
    steps:
      - name: Run tests
        run: |
          pytest tests/

  train:
    runs-on: ubuntu-latest
    needs: test
    steps:
      - name: Train model
        run: |
          python fraud_detection/pipeline/model_trainer.py

  evaluate:
    runs-on: ubuntu-latest
    needs: train
    steps:
      - name: Evaluate model
        run: |
          python fraud_detection/pipeline/model_evaluator.py

  log:
    runs-on: ubuntu-latest
    needs: evaluate
    steps:
      - name: Log to MLflow
        run: |
          python fraud_detection/pipeline/mlflow_logger.py
```

This structure outlines the necessary components for a CI/CD pipeline for a fraud detection model using scikit-learn and MLflow, with pytest for testing. It includes error handling and the automatic retraining trigger based on concept drift detection.
