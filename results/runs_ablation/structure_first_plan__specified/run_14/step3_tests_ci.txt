### (b) GitHub Actions YAML Workflow

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main
  schedule:
    - cron: '0 0 * * 0'  # Weekly schedule, adjust as needed

jobs:
  setup:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v2

      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.8'

  install-dependencies:
    runs-on: ubuntu-latest
    needs: setup
    steps:
      - name: Install dependencies
        run: pip install -r requirements.txt

  run-tests:
    runs-on: ubuntu-latest
    needs: install-dependencies
    steps:
      - name: Run Pytest
        run: pytest tests/

  run-pipeline:
    runs-on: ubuntu-latest
    needs: run-tests
    steps:
      - name: Run Pipeline
        run: python fraud_detection_pipeline/main.py
```

In the `pytest` test file, I have created a sample dataset using a fixture to test the data loading, preprocessing, training, and evaluation functions. The GitHub Actions workflow is structured to set up the environment, install dependencies, run tests, and finally execute the pipeline if the tests pass.
