To create a complete CI/CD pipeline for your fraud detection model using Python, pytest, and GitHub Actions, we need to build three main components: the Python pipeline module, the pytest test file, and the GitHub Actions workflow. This setup ensures that every run is reproducible by seeding all sources of randomness.

### Python Pipeline Module

First, we will create a Python module for the fraud detection model. This module will include data preparation, model training, and prediction functions.

```python
# fraud_detection_pipeline.py

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

RANDOM_SEED = 42

def generate_synthetic_data(n_samples=1000):
    np.random.seed(RANDOM_SEED)
    X = np.random.rand(n_samples, 10)
    y = np.random.randint(0, 2, n_samples)
    return X, y

def train_model(X, y):
    np.random.seed(RANDOM_SEED)
    model = RandomForestClassifier(random_state=RANDOM_SEED)
    model.fit(X, y)
    return model

def evaluate_model(model, X, y):
    y_pred = model.predict(X)
    accuracy = accuracy_score(y, y_pred)
    return accuracy

def main():
    # Generate synthetic data
    X, y = generate_synthetic_data()
    
    # Split the data
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=RANDOM_SEED)
    
    # Train the model
    model = train_model(X_train, y_train)
    
    # Evaluate the model
    accuracy = evaluate_model(model, X_test, y_test)
    print(f'Model accuracy: {accuracy:.2f}')

if __name__ == '__main__':
    main()
```

### Pytest Test File

Next, we'll create a pytest test file to verify the functionality of our pipeline.

```python
# test_fraud_detection_pipeline.py

import pytest
from fraud_detection_pipeline import generate_synthetic_data, train_model, evaluate_model

RANDOM_SEED = 42

def test_generate_synthetic_data():
    X, y = generate_synthetic_data()
    assert X.shape == (1000, 10)
    assert len(y) == 1000

def test_train_model():
    X, y = generate_synthetic_data()
    model = train_model(X, y)
    assert model is not None
    assert hasattr(model, "predict")

def test_evaluate_model():
    X, y = generate_synthetic_data()
    model = train_model(X, y)
    accuracy = evaluate_model(model, X, y)
    assert 0 <= accuracy <= 1

@pytest.fixture(autouse=True)
def set_random_seed():
    np.random.seed(RANDOM_SEED)
```

### GitHub Actions Workflow

Finally, we'll set up a GitHub Actions workflow to automate the testing process.

```yaml
# .github/workflows/ci.yml

name: CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v3

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install scikit-learn pytest

    - name: Run tests
      run: |
        pytest test_fraud_detection_pipeline.py
```

This setup provides a complete CI/CD pipeline for your fraud detection model. The pipeline ensures reproducibility by seeding all sources of randomness, both in the model training/testing process and in the synthetic data generation. The GitHub Actions workflow automates the testing process, running the tests every time you push changes to the main branch or open a pull request.
