Creating a CI/CD pipeline for a fraud detection model involves a series of steps to automate the testing, building, and deployment processes. Below, I will provide a Python module for the pipeline, a pytest test file, and a GitHub Actions workflow. Each component is designed to ensure reproducibility, with seeds set for any randomness.

### Python Pipeline Module

This Python script includes model training and evaluation, and it ensures reproducibility by setting seeds for any random operations.

```python
# pipeline.py

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score
import joblib

RANDOM_SEED = 42

def load_data():
    # For simplicity, we generate synthetic data
    np.random.seed(RANDOM_SEED)
    X = np.random.rand(1000, 20)
    y = np.random.randint(0, 2, 1000)
    return X, y

def preprocess_data(X, y):
    np.random.seed(RANDOM_SEED)
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=RANDOM_SEED)
    return X_train, X_test, y_train, y_test

def train_model(X_train, y_train):
    np.random.seed(RANDOM_SEED)
    model = RandomForestClassifier(random_state=RANDOM_SEED)
    model.fit(X_train, y_train)
    return model

def evaluate_model(model, X_test, y_test):
    predictions = model.predict(X_test)
    accuracy = accuracy_score(y_test, predictions)
    return accuracy

def save_model(model, filepath):
    joblib.dump(model, filepath)

def main():
    X, y = load_data()
    X_train, X_test, y_train, y_test = preprocess_data(X, y)
    model = train_model(X_train, y_train)
    accuracy = evaluate_model(model, X_test, y_test)
    print(f'Model accuracy: {accuracy}')
    save_model(model, 'fraud_detection_model.pkl')

if __name__ == '__main__':
    main()
```

### Pytest Test File

The test file includes unit tests for each function in the pipeline, with seeds set for reproducibility.

```python
# test_pipeline.py

import pytest
import numpy as np
from pipeline import load_data, preprocess_data, train_model, evaluate_model, RANDOM_SEED

def test_load_data():
    X, y = load_data()
    assert X.shape == (1000, 20)
    assert y.shape == (1000,)
    assert np.all((y == 0) | (y == 1))  # Check binary classification

def test_preprocess_data():
    X, y = load_data()
    X_train, X_test, y_train, y_test = preprocess_data(X, y)
    assert X_train.shape[0] == 800
    assert X_test.shape[0] == 200

def test_train_model():
    X, y = load_data()
    X_train, X_test, y_train, y_test = preprocess_data(X, y)
    model = train_model(X_train, y_train)
    assert hasattr(model, "predict")

def test_evaluate_model():
    X, y = load_data()
    X_train, X_test, y_train, y_test = preprocess_data(X, y)
    model = train_model(X_train, y_train)
    accuracy = evaluate_model(model, X_test, y_test)
    assert 0 <= accuracy <= 1

if __name__ == '__main__':
    pytest.main()
```

### GitHub Actions Workflow

This GitHub Actions workflow is triggered on pushes or pull requests and runs the pipeline's tests.

```yaml
# .github/workflows/ci-cd.yml

name: CI/CD for Fraud Detection Model

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout repository
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install sklearn joblib pytest

    - name: Run tests
      run: |
        pytest test_pipeline.py
```

This setup ensures that every run is reproducible due to the fixed random seeds and provides a full CI/CD pipeline for a fraud detection model using Python and GitHub Actions.
