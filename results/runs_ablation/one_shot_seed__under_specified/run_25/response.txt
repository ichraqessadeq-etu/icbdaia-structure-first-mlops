Creating a CI/CD pipeline for a fraud detection model involves several steps including model training, testing, and deployment. Below is a simplified version of such a pipeline using a Python module for the model, a Pytest test file to test the model, and a GitHub Actions workflow for CI/CD. The sample code provided is kept simple for clarity.

### 1. Python Pipeline Module

Here is the Python module for training a fraud detection model. Note that for reproducibility, we set the random seed for any part of the code that involves randomness.

```python
# fraud_detection_pipeline.py

import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score
import joblib

# Set random seed for reproducibility
SEED = 42
np.random.seed(SEED)

def load_data():
    # Generating synthetic data for illustration
    num_samples = 1000
    num_features = 10
    X = np.random.rand(num_samples, num_features)
    y = np.random.randint(0, 2, num_samples)
    return X, y

def preprocess_data(X, y):
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=SEED)
    return X_train, X_test, y_train, y_test

def train_model(X_train, y_train):
    model = RandomForestClassifier(random_state=SEED)
    model.fit(X_train, y_train)
    return model

def evaluate_model(model, X_test, y_test):
    predictions = model.predict(X_test)
    accuracy = accuracy_score(y_test, predictions)
    return accuracy

def save_model(model, filepath='model.pkl'):
    joblib.dump(model, filepath)

def run_pipeline():
    X, y = load_data()
    X_train, X_test, y_train, y_test = preprocess_data(X, y)
    model = train_model(X_train, y_train)
    accuracy = evaluate_model(model, X_test, y_test)
    save_model(model)
    return accuracy

if __name__ == "__main__":
    accuracy = run_pipeline()
    print(f"Model accuracy: {accuracy}")
```

### 2. Pytest Test File

Here is a Pytest test file to test the model's functionality. We ensure reproducibility by setting the random seed for any synthetic data generation.

```python
# test_fraud_detection.py

import numpy as np
import pytest
from fraud_detection_pipeline import load_data, preprocess_data, train_model, evaluate_model

# Set random seed for reproducibility
SEED = 42
np.random.seed(SEED)

def test_data_loading():
    X, y = load_data()
    assert X is not None
    assert y is not None
    assert X.shape[0] == y.shape[0]

def test_preprocess_data():
    X, y = load_data()
    X_train, X_test, y_train, y_test = preprocess_data(X, y)
    assert X_train.shape[0] + X_test.shape[0] == X.shape[0]
    assert y_train.shape[0] + y_test.shape[0] == y.shape[0]

def test_model_training():
    X, y = load_data()
    X_train, _, y_train, _ = preprocess_data(X, y)
    model = train_model(X_train, y_train)
    assert model is not None
    assert hasattr(model, "predict")

def test_model_evaluation():
    X, y = load_data()
    X_train, X_test, y_train, y_test = preprocess_data(X, y)
    model = train_model(X_train, y_train)
    accuracy = evaluate_model(model, X_test, y_test)
    assert isinstance(accuracy, float)
    assert 0 <= accuracy <= 1
```

### 3. GitHub Actions Workflow

Here is a GitHub Actions workflow for the CI/CD pipeline. This workflow will run the tests every time there is a push or pull request to the `main` branch.

```yaml
# .github/workflows/ci-cd-pipeline.yml

name: CI/CD Pipeline

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build-and-test:
    runs-on: ubuntu-latest

    strategy:
      matrix:
        python-version: [3.8, 3.9, 3.10]

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: ${{ matrix.python-version }}

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install scikit-learn joblib pytest

    - name: Run tests
      run: pytest
```

This setup provides a complete CI/CD pipeline that includes model training, testing, and deployment capabilities, ensuring reproducibility by setting random seeds. Adjust the pipeline according to your project needs, especially when using real datasets or more complex model architectures.
