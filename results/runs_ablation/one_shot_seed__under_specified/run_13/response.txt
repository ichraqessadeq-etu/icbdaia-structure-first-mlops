### Python Pipeline Module

Let's assume you are using a simple logistic regression model for fraud detection.

```python
# fraud_detection_pipeline.py

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, precision_score, recall_score

RANDOM_SEED = 42
np.random.seed(RANDOM_SEED)

def generate_synthetic_data(n_samples=1000):
    np.random.seed(RANDOM_SEED)
    X = np.random.rand(n_samples, 10)
    y = (np.sum(X, axis=1) > 5).astype(int)  # Simple threshold to create a binary target
    return pd.DataFrame(X, columns=[f'feature_{i}' for i in range(10)]), pd.Series(y, name='target')

def train_model(X_train, y_train):
    model = LogisticRegression(random_state=RANDOM_SEED)
    model.fit(X_train, y_train)
    return model

def evaluate_model(model, X_test, y_test):
    predictions = model.predict(X_test)
    accuracy = accuracy_score(y_test, predictions)
    precision = precision_score(y_test, predictions)
    recall = recall_score(y_test, predictions)
    return accuracy, precision, recall

def main():
    X, y = generate_synthetic_data()
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=RANDOM_SEED)
    model = train_model(X_train, y_train)
    accuracy, precision, recall = evaluate_model(model, X_test, y_test)
    return accuracy, precision, recall

if __name__ == "__main__":
    accuracy, precision, recall = main()
    print(f"Accuracy: {accuracy}, Precision: {precision}, Recall: {recall}")
```

RANDOM_SEED = 42

def test_train_model():

    assert model is not None
    assert hasattr(model, 'predict')

def test_evaluate_model():

### GitHub Actions Workflow

Here is a simple GitHub Actions workflow file to automate testing when code is pushed to the repository.

```yaml
# .github/workflows/ci.yml

name: CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install scikit-learn pandas pytest

    - name: Run tests
      run: |
        pytest
```

### Explanation

- **Python Pipeline Module**: This script generates synthetic data, trains a logistic regression model, and evaluates it. All randomness is controlled by setting a seed.
  
- **Pytest Test File**: This file contains unit tests for the functions in the pipeline. It checks the shape of the synthetic data, the training process, and the evaluation metrics.

- **GitHub Actions Workflow**: This YAML configuration runs the tests automatically on every push or pull request to the `main` branch. It sets up a Python environment, installs dependencies, and runs the tests.

By following this setup, you ensure that your CI/CD pipeline is reproducible and automated, providing a consistent method to validate changes to your fraud detection model.
