### Python Pipeline Module

We'll assume the fraud detection model is implemented using the `scikit-learn` library. The pipeline will train a simple logistic regression model on synthetic data.

```python
# fraud_detection_pipeline.py

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score
from sklearn.datasets import make_classification

RANDOM_SEED = 42

def generate_synthetic_data(seed=RANDOM_SEED):
    np.random.seed(seed)
    X, y = make_classification(n_samples=1000, n_features=20, n_informative=2, n_redundant=10, random_state=seed)
    return X, y

def train_model(X, y, seed=RANDOM_SEED):
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=seed)
    model = LogisticRegression(random_state=seed)
    model.fit(X_train, y_train)
    predictions = model.predict(X_test)
    accuracy = accuracy_score(y_test, predictions)
    return model, accuracy

if __name__ == "__main__":
    X, y = generate_synthetic_data()
    model, accuracy = train_model(X, y)
    print(f"Model trained with accuracy: {accuracy:.2f}")
```

### Pytest Test File

This test file will ensure that the pipeline works correctly and produces consistent results.

```python
# test_fraud_detection_pipeline.py

import pytest
from fraud_detection_pipeline import generate_synthetic_data, train_model, RANDOM_SEED

def test_generate_synthetic_data():
    X, y = generate_synthetic_data()
    assert X.shape == (1000, 20)
    assert len(y) == 1000

def test_train_model():
    X, y = generate_synthetic_data()
    model, accuracy = train_model(X, y)
    assert model is not None
    assert 0 <= accuracy <= 1
    # Check for reproducibility
    _, accuracy_repeated = train_model(X, y)
    assert accuracy == pytest.approx(accuracy_repeated, rel=1e-9)

if __name__ == "__main__":
    pytest.main()
```

### GitHub Actions Workflow

This workflow will run the tests every time there is a push or pull request to the main branch.

```yaml
# .github/workflows/ci-cd-pipeline.yml

name: CI/CD Pipeline

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout repository
      uses: actions/checkout@v3

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install scikit-learn pytest

    - name: Run tests
      run: |
        pytest test_fraud_detection_pipeline.py
```

- **Python Pipeline Module:** This module generates synthetic data, trains a logistic regression model, and checks its accuracy. The random seed ensures reproducibility.
  
- **Pytest Test File:** This file includes tests for both data generation and model training functions. It also checks if the training process is reproducible by testing the model accuracy twice.

- **GitHub Actions Workflow:** This workflow is triggered on push or pull requests to the main branch. It sets up Python, installs necessary dependencies, and runs the tests using pytest.

By following this setup, you ensure that every run of the pipeline and tests is consistent and reproducible.
