### (b) GitHub Actions Workflow

```yaml
# .github/workflows/ci.yml

name: CI

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pytest
        # Add other dependencies like pandas, scikit-learn, etc.

    - name: Run tests
      run: pytest tests/
```

In this setup, the test file uses mock data to simulate function behavior, and the GitHub Actions workflow runs tests automatically on code pushes and pull requests to the `main` branch. Adjust the `expected_data`, `expected_cleaned_data`, and other placeholders with actual mock values depending on your implementation.
