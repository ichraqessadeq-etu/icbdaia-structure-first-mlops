### (b) GitHub Actions Workflow

Let's create a GitHub Actions workflow named `python-app.yml` to automate the testing process.

```yaml
# .github/workflows/python-app.yml

name: Python application

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:

    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2
      
    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pandas scikit-learn joblib pytest

    - name: Run tests
      run: |
        pytest test_pipeline.py
```

This setup includes:

1. **Pytest Test File**: Covers loading, cleaning, feature engineering, splitting, training, and evaluating functions. It uses pytest fixtures for sample data and asserts expected conditions.

2. **GitHub Actions Workflow**: Automates testing on every push or pull request to the `main` branch. It sets up a Python environment, installs necessary dependencies, and runs the tests.
