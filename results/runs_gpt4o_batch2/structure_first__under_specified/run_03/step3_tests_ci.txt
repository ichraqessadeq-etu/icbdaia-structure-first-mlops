### (b) Complete GitHub Actions Workflow

This GitHub Actions workflow will run your tests each time you push changes to the repository:

```yaml
# .github/workflows/ci.yml

name: CI

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout repository
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt

    - name: Run tests
      run: |
        pytest tests/
```

Make sure to adjust file paths and test conditions according to your actual implementation. Also, ensure your `requirements.txt` file includes all necessary dependencies for running the tests.
