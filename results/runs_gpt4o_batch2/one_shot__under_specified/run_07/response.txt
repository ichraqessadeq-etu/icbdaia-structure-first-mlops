Creating a CI/CD pipeline for a fraud detection model involves setting up automated tests and deployment processes for your model. Below, I will provide you with a full Python pipeline module, a pytest test file, and a GitHub Actions workflow. This setup assumes that you have a machine learning model already developed and that you are using Python for your codebase.

### Python Pipeline Module

Let's assume your fraud detection model is built using a Python script called `fraud_detection_model.py`. We'll create a `pipeline.py` module to handle the process of training, evaluating, and saving the model.

```python
# pipeline.py

import joblib
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

class FraudDetectionPipeline:
    def __init__(self):
        self.model = RandomForestClassifier()

    def load_data(self):
        # Example using synthetic data; replace with actual data loading
        X, y = make_classification(n_samples=1000, n_features=20, n_classes=2, random_state=42)
        return train_test_split(X, y, test_size=0.3, random_state=42)

    def train(self, X_train, y_train):
        self.model.fit(X_train, y_train)

    def evaluate(self, X_test, y_test):
        predictions = self.model.predict(X_test)
        return accuracy_score(y_test, predictions)

    def save_model(self, file_path):
        joblib.dump(self.model, file_path)

    def run_pipeline(self, model_path='fraud_model.pkl'):
        X_train, X_test, y_train, y_test = self.load_data()
        self.train(X_train, y_train)
        accuracy = self.evaluate(X_test, y_test)
        print(f'Model accuracy: {accuracy}')
        self.save_model(model_path)

if __name__ == '__main__':
    pipeline = FraudDetectionPipeline()
    pipeline.run_pipeline()
```

### Pytest Test File

We'll write some basic tests to ensure the pipeline works as expected. Create a file named `test_pipeline.py`.

```python
# test_pipeline.py

import pytest
from pipeline import FraudDetectionPipeline

@pytest.fixture
def pipeline():
    return FraudDetectionPipeline()

def test_load_data(pipeline):
    X_train, X_test, y_train, y_test = pipeline.load_data()
    assert X_train.shape[0] > 0
    assert X_test.shape[0] > 0
    assert len(y_train) > 0
    assert len(y_test) > 0

def test_train(pipeline):
    X_train, X_test, y_train, y_test = pipeline.load_data()
    pipeline.train(X_train, y_train)
    assert pipeline.model is not None

def test_evaluate(pipeline):
    X_train, X_test, y_train, y_test = pipeline.load_data()
    pipeline.train(X_train, y_train)
    accuracy = pipeline.evaluate(X_test, y_test)
    assert 0 <= accuracy <= 1

def test_save_model(pipeline, tmp_path):
    model_path = tmp_path / "model.pkl"
    pipeline.run_pipeline(model_path)
    assert model_path.exists()
```

### GitHub Actions Workflow

Create a file named `.github/workflows/ci-cd.yml` to define your GitHub Actions workflow.

```yaml
# .github/workflows/ci-cd.yml

name: CI/CD Pipeline

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.x'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install joblib scikit-learn pytest

    - name: Run tests
      run: |
        pytest

    - name: Build and Save Model
      run: |
        python pipeline.py
```

This setup includes:

1. **Python Pipeline Module**: Handles data loading, training, evaluating, and saving the model.
2. **Pytest Test File**: Contains tests for each step of the pipeline to ensure it functions correctly.
3. **GitHub Actions Workflow**: Automates the testing and model building process on every push or pull request to the `main` branch.

Make sure you have the necessary dependencies installed and your GitHub repository is set up with the appropriate branch (`main` in this example). You can customize the pipeline further based on your specific needs and environment.
