Creating a CI/CD pipeline for a fraud detection model involves setting up a Python module for the pipeline, writing tests using `pytest`, and configuring a GitHub Actions workflow to automate the process. Here's how you can set it up:

### Python Pipeline Module

This module will include basic steps like data preprocessing, model training, and evaluation.

```python
# fraud_detection_pipeline.py
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    # Assuming 'label' is the target column and others are features
    X = data.drop(columns=['label'])
    y = data['label']
    return X, y

def split_data(X, y, test_size=0.2, random_state=42):
    return train_test_split(X, y, test_size=test_size, random_state=random_state)

def train_model(X_train, y_train):
    model = RandomForestClassifier(random_state=42)
    model.fit(X_train, y_train)
    return model

def evaluate_model(model, X_test, y_test):
    predictions = model.predict(X_test)
    accuracy = accuracy_score(y_test, predictions)
    precision = precision_score(y_test, predictions)
    recall = recall_score(y_test, predictions)
    return accuracy, precision, recall

def main(file_path):
    data = load_data(file_path)
    X, y = preprocess_data(data)
    X_train, X_test, y_train, y_test = split_data(X, y)
    model = train_model(X_train, y_train)
    return evaluate_model(model, X_test, y_test)
```

### Pytest Test File

Here, you'll write tests to check the functionality of each step in your pipeline.

```python
# test_fraud_detection_pipeline.py
import pytest
from fraud_detection_pipeline import load_data, preprocess_data, split_data, train_model, evaluate_model
import pandas as pd
from sklearn.ensemble import RandomForestClassifier

@pytest.fixture
def sample_data():
    data = {
        'feature1': [1, 2, 3, 4, 5],
        'feature2': [5, 4, 3, 2, 1],
        'label': [0, 1, 0, 1, 0]
    }
    return pd.DataFrame(data)

def test_load_data(sample_data):
    data = load_data("sample.csv")
    assert not data.empty

def test_preprocess_data(sample_data):
    X, y = preprocess_data(sample_data)
    assert X.shape[0] == y.shape[0]

def test_split_data(sample_data):
    X, y = preprocess_data(sample_data)
    X_train, X_test, y_train, y_test = split_data(X, y)
    assert len(X_train) + len(X_test) == len(X)
    assert len(y_train) + len(y_test) == len(y)

def test_train_model(sample_data):
    X, y = preprocess_data(sample_data)
    X_train, X_test, y_train, y_test = split_data(X, y)
    model = train_model(X_train, y_train)
    assert isinstance(model, RandomForestClassifier)

def test_evaluate_model(sample_data):
    X, y = preprocess_data(sample_data)
    X_train, X_test, y_train, y_test = split_data(X, y)
    model = train_model(X_train, y_train)
    accuracy, precision, recall = evaluate_model(model, X_test, y_test)
    assert 0 <= accuracy <= 1
    assert 0 <= precision <= 1
    assert 0 <= recall <= 1
```

### GitHub Actions Workflow

This YAML file will automate the testing process when you push changes to your repository.

```yaml
# .github/workflows/ci-cd.yml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pandas scikit-learn pytest

    - name: Run tests
      run: |
        pytest test_fraud_detection_pipeline.py
```

This setup will allow you to automatically run tests on your fraud detection model pipeline whenever you make changes to your codebase. Make sure you have a sample data file named `sample.csv` in your repository for the tests to run successfully, or adjust the test script to accommodate a different data source.
