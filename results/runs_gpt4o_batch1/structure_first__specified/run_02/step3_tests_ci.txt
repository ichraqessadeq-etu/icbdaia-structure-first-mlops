import pytest
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

@pytest.fixture

    """Fixture for creating a small sample dataset."""

    """Test the model training function."""
    X_train = sample_data.drop(columns=['target'])
    y_train = sample_data['target']
    model = train_model(X_train, y_train)
    assert isinstance(model, RandomForestClassifier)

    """Test the model evaluation function."""

### (b) GitHub Actions Workflow

```yaml
# .github/workflows/ci.yml

name: CI

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
        pip install pytest

    - name: Test with pytest
      run: |
        pytest --maxfail=1 --disable-warnings

    - name: Display test results
      run: |
        pytest --maxfail=1 --disable-warnings --junitxml=test-results.xml

    - name: Upload test results
      uses: actions/upload-artifact@v2
      with:
        name: test-results
        path: test-results.xml
```

This setup includes a pytest test suite that verifies the functionality of the pipeline components and a GitHub Actions workflow that automates the testing process on every push and pull request to the main branch. The workflow installs dependencies, runs the tests, and uploads the test results as an artifact.
