def test_load_data():

    mock_data = pd.DataFrame({'feature1': [1, 2], 'feature2': [3, 4], 'target': [0, 1]})

def test_train_model():

    model = train_model(X_train, y_train)

### (b) GitHub Actions Workflow
Here is the `ci.yml` file to automate the testing using GitHub Actions.

```yaml
# .github/workflows/ci.yml

name: CI

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  test:
    runs-on: ubuntu-latest

    strategy:
      matrix:
        python-version: [3.8, 3.9, 3.10]

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python ${{ matrix.python-version }}
      uses: actions/setup-python@v2
      with:
        python-version: ${{ matrix.python-version }}

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pytest pandas scikit-learn mlflow

    - name: Run tests
      run: |
        pytest tests/
```

This setup ensures that the pipeline is tested for different Python versions (3.8, 3.9, and 3.10) and that each component of the pipeline is covered by unit tests. The tests are executed automatically on GitHub whenever code is pushed to or a pull request is made against the `main` branch.
