### (b) GitHub Actions Workflow

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
        pip install pytest

    - name: Run tests
      run: |
        pytest tests/
```

### Explanation

- **Pytest Test File:**
  - We utilize fixtures to load sample data once and reuse it across multiple tests.
  - We test each component of the pipeline: data loading, model training, evaluation, and MLflow logging.
  - For MLflow logging, we ensure the function runs without error since actual verification requires a more complex setup involving MLflow's tracking server.

- **GitHub Actions Workflow:**
  - The workflow triggers on pushes and pull requests to the main branch.
  - It sets up a Python environment, installs dependencies, and runs the tests using pytest.
  - The `requirements.txt` file should list necessary dependencies like `pandas`, `scikit-learn`, `mlflow`, and `pytest`.
