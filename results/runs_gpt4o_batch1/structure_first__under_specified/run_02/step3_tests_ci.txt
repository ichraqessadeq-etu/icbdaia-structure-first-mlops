### (b) GitHub Actions Workflow

Below is a GitHub Actions workflow file to automate testing using the pytest framework.

```yaml
# .github/workflows/ci.yml

name: CI

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout repository
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
        pip install pytest

    - name: Run tests
      run: |
        pytest tests/
```

This workflow will run on every push and pull request to the main branch. It checks out the repository, sets up Python, installs necessary dependencies, and runs the tests using pytest.
