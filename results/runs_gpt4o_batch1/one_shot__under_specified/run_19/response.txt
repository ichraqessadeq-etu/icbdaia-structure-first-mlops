Creating a CI/CD pipeline for a fraud detection model involves several steps, including building the model, testing it, and deploying it using GitHub Actions. I'll provide you with a simplified example of how you might structure your pipeline in Python, write test cases using `pytest`, and set up a GitHub Actions workflow.

### Python Pipeline Module

Let's assume you have a Python module called `fraud_detection.py` which contains a simple function `train_model` that trains your fraud detection model.

```python
# fraud_detection.py

import joblib
from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier

def train_model():
    # Create a simple dataset
    X, y = make_classification(n_samples=1000, n_features=20, random_state=42)
    
    # Initialize the model
    model = RandomForestClassifier(n_estimators=100, random_state=42)
    
    # Train the model
    model.fit(X, y)
    
    # Save the model
    joblib.dump(model, 'fraud_detection_model.pkl')
    
    return model

def load_model(model_path='fraud_detection_model.pkl'):
    return joblib.load(model_path)
```

### Pytest Test File

Next, we create a test file named `test_fraud_detection.py` to test the functionality of our `fraud_detection.py` module.

```python
# test_fraud_detection.py

import pytest
from sklearn.ensemble import RandomForestClassifier
from fraud_detection import train_model, load_model

def test_train_model():
    model = train_model()
    assert isinstance(model, RandomForestClassifier), "Model should be a RandomForestClassifier"
    assert hasattr(model, 'predict'), "Model should have a predict method"

def test_model_saving_loading():
    # Train and save the model
    train_model()
    
    # Load the model
    model = load_model()
    
    assert isinstance(model, RandomForestClassifier), "Loaded model should be a RandomForestClassifier"
    assert hasattr(model, 'predict'), "Loaded model should have a predict method"
```

### GitHub Actions Workflow

Finally, we create a GitHub Actions workflow file in `.github/workflows` directory named `ci-cd-pipeline.yml`.

```yaml
# .github/workflows/ci-cd-pipeline.yml

name: CI/CD Pipeline

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install scikit-learn joblib pytest

    - name: Run tests
      run: |
        pytest test_fraud_detection.py

    - name: Train and save model
      run: |
        python -c "from fraud_detection import train_model; train_model()"

    - name: Upload model artifact
      uses: actions/upload-artifact@v2
      with:
        name: model
        path: fraud_detection_model.pkl
```

### Explanation

- **Python Pipeline Module:** Implements the logic for training and saving the model.
- **Pytest Test File:** Contains tests to ensure the model is trained and saved correctly.
- **GitHub Actions Workflow:** Automates the process of testing the code and building the model every time you push changes to the main branch or create a pull request against it. It includes steps for checking out the code, setting up Python, installing dependencies, running tests, training the model, and uploading the trained model as an artifact.

This setup provides a basic CI/CD pipeline for your fraud detection model. Adjust the configurations and dependencies as necessary for your specific use case.
