## GitHub Actions Workflow Outline

### `.github/workflows/ci-cd.yml`

```yaml
name: Fraud Detection Model CI/CD

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]
  workflow_dispatch:

env:
  PYTHON_VERSION: "3.10"
  MODEL_NAME: "fraud-detection-model"

jobs:
  code-quality:
    steps:
      - Checkout code
      - Setup Python
      - Install dependencies
      - Run linting (flake8, black)
      - Run type checking (mypy)
      - Run security scan (bandit)

  unit-tests:
    steps:
      - Checkout code
      - Setup Python
      - Install dependencies
      - Run pytest with coverage
      - Upload coverage reports
      - Check coverage threshold (80%)

  data-validation:
    needs: [unit-tests]
    steps:
      - Checkout code
      - Setup Python
      - Download sample dataset
      - Run data validation pipeline
      - Upload validation report

  model-training:
    needs: [data-validation]
    steps:
      - Checkout code
      - Setup Python
      - Download validated data
      - Train model
      - Save model artifacts
      - Upload trained model

  model-evaluation:
    needs: [model-training]
    steps:
      - Checkout code
      - Setup Python
      - Download trained model
      - Run evaluation pipeline
      - Compare with baseline metrics
      - Upload evaluation report
      - Fail if metrics below threshold

  model-registration:
    needs: [model-evaluation]
    if: github.ref == 'refs/heads/main'
    steps:
      - Checkout code
      - Setup Python
      - Download model artifacts
      - Register model in MLflow
      - Tag with git commit SHA
      - Store model version

  deploy-staging:
    needs: [model-registration]
    if: github.ref == 'refs/heads/main'
    steps:
      - Checkout code
      - Setup cloud credentials
      - Build Docker container
      - Push to container registry
      - Deploy to staging environment
      - Run smoke tests
      - Validate endpoint health

  deploy-production:
    needs: [deploy-staging]
    if: github.ref == 'refs/heads/main'
    environment: production
    steps:
      - Checkout code
      - Setup cloud credentials
      - Require manual approval
      - Deploy to production (blue-green)
      - Run production smoke tests
      - Switch traffic to new version
      - Monitor metrics
      - Rollback on failure

  notify:
    needs: [deploy-production]
    if: always()
    steps:
      - Send Slack notification
      - Update deployment dashboard
```
