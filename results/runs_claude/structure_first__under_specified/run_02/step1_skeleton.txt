## GitHub Actions Workflow (`.github/workflows/ml-pipeline.yml`)

```yaml
name: ML Pipeline CI/CD

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]
  schedule:
    - cron: '0 0 * * 0'  # Weekly retraining

jobs:
  # Job 1: Code Quality & Linting
  code-quality:
    steps:
      - Checkout code
      - Setup Python
      - Install dependencies
      - Run black formatter check
      - Run flake8 linter
      - Run mypy type checking
      - Run bandit security scan

  # Job 2: Unit & Integration Tests
  test:
    steps:
      - Checkout code
      - Setup Python
      - Install dependencies
      - Run pytest with coverage
      - Generate coverage report
      - Upload coverage to codecov

  # Job 3: Data Validation
  data-validation:
    steps:
      - Checkout code
      - Setup Python & dependencies
      - Download latest data
      - Validate data schema
      - Check data quality metrics
      - Detect data drift
      - Generate data report

  # Job 4: Model Training
  train:
    needs: [code-quality, test, data-validation]
    steps:
      - Checkout code
      - Setup Python & dependencies
      - Setup DVC for data versioning
      - Load training data
      - Train model
      - Save model artifacts
      - Upload model to artifact storage

  # Job 5: Model Evaluation
  evaluate:
    needs: train
    steps:
      - Download trained model
      - Load test data
      - Evaluate model performance
      - Check performance thresholds
      - Run bias detection tests
      - Generate evaluation report
      - Upload metrics

  # Job 6: Model Validation & Testing
  model-validation:
    needs: evaluate
    steps:
      - Download model artifacts
      - Run model unit tests
      - Test model inference
      - Validate prediction latency
      - Check model size constraints
      - Test model serialization

  # Job 7: Security & Compliance
  security-scan:
    needs: model-validation
    steps:
      - Scan dependencies for vulnerabilities
      - Check model for adversarial robustness
      - Validate data privacy compliance
      - Generate security report

  # Job 8: Model Registry & Versioning
  register-model:
    needs: [evaluate, model-validation, security-scan]
    if: github.ref == 'refs/heads/main'
    steps:
      - Download model artifacts
      - Version model with semantic versioning
      - Register model in MLflow/registry
      - Generate model card
      - Tag model with metadata
      - Create GitHub release

  # Job 9: Staging Deployment
  deploy-staging:
    needs: register-model
    if: github.ref == 'refs/heads/main'
    steps:
      - Download versioned model
      - Build Docker container
      - Push to container registry
      - Deploy to staging environment
      - Run smoke tests
      - Health check endpoint

  # Job 10: Integration Tests (Staging)
  integration-test-staging:
    needs: deploy-staging
    steps:
      - Run API integration tests
      - Test prediction endpoints
      - Load testing
      - Validate response times
      - Check error handling

  # Job 11: Production Deployment
  deploy-production:
    needs: integration-test-staging
    if: github.ref == 'refs/heads/main'
    environment: production
    steps:
      - Require manual approval
      - Deploy to production (blue-green)
      - Run production smoke tests
      - Monitor initial metrics
      - Switch traffic gradually
      - Rollback capability ready

  # Job 12: Post-Deployment Monitoring
  monitor:
    needs: deploy-production
    steps:
      - Setup monitoring dashboards
      - Configure alerts
      - Track prediction metrics
      - Monitor model drift
      - Log performance metrics
      - Send notification on completion
```
